# Assets für den Fobizz-Bot „Löslichkeit von CO₂ in Wasser“

Dieses Repository enthält Medien für einen Lernbot zum Experiment „Löslichkeit von CO₂ in Wasser“.

- `docs/index.html`: Medienkatalog für GitHub Pages mit kopierbaren Bot-URLs
- `docs/medien/`: Bilder und animierte GIF-Dateien
- `docs/medien.json`: maschinenlesbare Beschreibungen, Alt-Texte und Einsatzhinweise
- `docs/QUELLEN-UND-LIZENZEN.md`: vorhandene Quellenangaben und noch offene Lizenzangaben

## GitHub Pages

In den Repository-Einstellungen unter **Pages** als Quelle den Branch und den Ordner `/docs` auswählen. Auf der veröffentlichten Katalogseite erzeugt die Schaltfläche „Bot-URL kopieren“ automatisch die richtige absolute Adresse für das jeweilige Medium.

Die Medien liegen unter `docs/medien/`. Veröffentlichte URLs haben deshalb dieses Schema:

```text
https://reifab.github.io/assets-fobizz-bot-co2-in-water-experiment/medien/DATEINAME
```
